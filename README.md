# 🎮 Snake and Ladder Game

A classic Snake and Ladder board game built with vanilla HTML, CSS, and JavaScript. Perfect for playing in your browser!

## Features

✨ **Interactive Gameplay**
- Two-player turn-based game
- Real-time position updates
- Smooth animations and transitions

🎲 **Game Mechanics**
- Roll dice to move forward
- Climb ladders to advance faster
- Avoid snakes that pull you backward
- First to reach position 100 wins!

🎨 **Beautiful UI**
- Responsive design (works on mobile and desktop)
- Gradient backgrounds and smooth animations
- Clear visual feedback for snakes and ladders
- Player status indicators

## How to Play

1. **Start the Game**: Open `index.html` in your browser
2. **Take Turns**: Players alternate rolling the dice
3. **Move**: Your position advances by the dice value
4. **Ladders & Snakes**: 
   - Landing on a ladder base 🪜 moves you up
   - Landing on a snake head 🐍 moves you down
5. **Win**: First player to reach position 100 wins!

## Game Rules

1. Each player starts at position 1
2. Players take turns rolling the dice
3. Movement is determined by the dice value (1-6)
4. Landing on a ladder moves you up
5. Landing on a snake moves you down
6. You cannot move beyond position 100
7. First to reach exactly 100 wins
8. Use the "Reset Game" button to start over
